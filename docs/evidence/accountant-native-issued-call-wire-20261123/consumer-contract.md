# Retained issued-call wire contract

`retain_issued_call_wire(result)` accepts one original released `NativeIssuedCallFormatResult` on its original P adapter.
The method rejects a copied record before registration or callbacks.
An equal mapping, JSON value, or digest grants no operation authority.

One genuine attempt uses a bounded strong registry without a new source adapter attribute.
The registry retains at most 128 attempts without reclamation or retry.
Any failure after registration spends the attempt.

The method uses `result.binding.selection.destination.model_ref` to select conversion behavior.
The selection must use the exact built-in string `chat_completions`.
The model reference grants no destination or send authority.

The method constructs the original `ChatCompletionsTransport()` and calls its original bound `convert_messages` once.
Its input list contains the original formatter mapping by identity.
The helper removes `tool_name` and `timestamp` from a new row.
The original row and its timestamp remain unchanged.

The retained list has one row with ordered keys `role`, `name`, `content`, and `tool_call_id`.
Each string value keeps its original identity.
The aggregate keeps its original JSON spacing and order.
This fixed formatter mode has no risk or effect metadata.

Serialization uses `ensure_ascii=False`, `allow_nan=False`, compact separators, and strict UTF-8.
It adds no BOM or final LF and preserves scalar code points.
Each string has 16384-character and 16384-byte caps.
The existing 262144-byte new-value and 786432-byte combined caps remain unchanged.

Three wire windows check the original source proof and current operator authority.
The terminal validator checks original P/E/F registrations, snapshots, records, graph objects, controls, and helper identities.
It does not reopen an old active window.
Current selected grants, expiry, full coverage, producers, destinations, controls, and runtime health remain mandatory.
Alternative live coverage cannot replace an expired selected grant.

The single shared operation is `derive(F, (Mf,), wire_bytes, path="tool_result")`.
Wf has Mf as its sole parent and retains its restrictions after current labels disappear.
The method adds at most one content and no envelopes, sends, agents, qualifications, acceptances, or returns.
All existing shared limits remain unchanged.

The frozen and slotted `NativeIssuedCallWireResult` has six fields.
Their order is `source_result`, `model`, `messages`, `message_bytes`, `message_content`, and `anchors`.
The read-only `issued_call_wire_results` property returns original released records.
It grants proof access only.

A refusal after the helper keeps its actual output and any complete bytes.
A serialization failure keeps the raw object without byte evidence.
A refusal after Wf keeps its content and actual charge but publishes no wire result.
The first genuine control exception keeps its original identity.
