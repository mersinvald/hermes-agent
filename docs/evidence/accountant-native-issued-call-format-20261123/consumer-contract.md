# Issued-call formatter contract

The adapter formats one original terminal issued-call result.
The host supplies a genuine F capability, selection port, producer reference, and selected main route.
F shares the first six E holder facts.
F retains its own request handle, selection port, producer, transport port, and selected destination.

The catalog and genuine qualifications must exist before the original P runtime capture.
The formatter does not add routes, ports, profiles, or qualifications to that runtime.
Matching selection values can reuse genuine same-holder path grants.
They do not merge request handles, ports, producers, or selected destinations.

## Public surface

`bind_issued_call_format` accepts the original `NativeIssuedCallResult` and four keyword-only F configuration arguments.
`run_issued_call_format` accepts only the original opaque `NativeIssuedCallFormatInput`.
`issued_call_format_results` returns a tuple of original registered records.
The binding has twelve frozen, slotted fields.
The result has six frozen, slotted fields.

A copy grants no authority.
A second bind or run refuses the spent attempt.
A failed bind or run denies F and keeps original P/E state and proof.
The proof getter grants no formatter, source, or consumer operation.

## Source proof

The registered formatter window checks the original probe, observation, execution owner, binding, frame, invocation, return, and closed child.
It checks the complete 29-field child completion, actual entry, aggregate, and original ancestry.
It reads attached contexts and constructor anchors directly.
It does not call the old active-frame access guards or reopen a source window.

Every window checks genuine current P/E/R/M/F admission, selection, producer, destination, expiry, coverage, controls, and health.
Each original selected grant remains mandatory, even with other live coverage.
The first genuine control exception keeps its identity through shared normalization.
Callback depth blocks reentry before another native operation.

Bf includes the complete original call.
Initial F authority must cover every retained source restriction before Bf admission.
Later current-label removal keeps the Bf, If, and Mf restriction union.

## Four windows and three stages

| Window | Work |
| --- | --- |
| Bind | Validate source and F authority for Bf admission, If derivation, and the frozen binding. |
| Run entry | Check the original token, source, current authority, controls, and health. |

| Release | Check original associations and mapping anchors before the terminal result. |

Bf uses native canonical JSON with `format_mode`, `source_call`, `formatter_holder`, `selection`, `producer_policy`, and `main_route_ref`.
The format mode is `delegate_result_v1`.

The formatter receives only the original observation name, original aggregate string, and original canonical call ID.
It calls `make_tool_result_message(name, content, tool_call_id)` without an effect argument.

The policy clock and actual captured formatter wall clock remain separate.

A rejected raw output grants no released result or consumer authority.
Failures retain genuine charges and complete source proof.
